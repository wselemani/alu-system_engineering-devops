# Web server

This project covers web server basics: transferring files to a server with scp,
installing and configuring Nginx, and setting up a domain name.

## Files

- `0-transfer_file`: Bash script that transfers a file to a server with scp
- `1-install_nginx_web_server`: Bash script that installs Nginx and serves a page containing "Holberton School" on port 80
